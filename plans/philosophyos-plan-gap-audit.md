# PhilosophyOS 计划对账

日期：2026-08-01

## 结论

当前最接近“可收尾”的是功能 Beta，只剩 `4.3 收紧 Beta 导航与发布说明`。真正需要补齐的，不是核心闭环本身，而是三类遗漏：

1. 产品文档里已经写了，但还没拆成执行计划。
2. 旧 MVP 计划里仍有一批 Obsidian 与社交能力未完成。
3. 商业化路线需要单独立项，不能只停留在概念层。

## 已完成或已被 Beta 覆盖

- 每日命题、AI 对话、思想快照、思想档案、关系图谱。
- 本地 SQLite 存储与会话恢复。
- 模型配置与前端切换。
- 西方哲学家图鉴。
- 启动、健康检查、E2E 与恢复测试。

## 仍在功能 Beta 里

- `4.3` 收紧 Beta 导航与发布说明。

建议目标：

- 只保留已完成模块入口。
- 补齐安装、备份、隐私、故障恢复说明。
- 明确数据位置与 API Key 边界。

- `3.4` 确认写入、冲突检测和撤销
- `3.5` 笔记工作台

### 个人思想档案

- `4.1` 观点卡片与开放问题状态
- `4.2` 观点变化候选
- `4.3` 思想档案与隐私控制页面

### 好友哲学讨论

- `5.2` 私密讨论房间和权限
- `5.3` 多人讨论主持与独立总结
- `5.4` 好友、邀请和讨论页面
- `5.5` 社交通知、安全限制和权限回归

### 质量与发布

- `6.1` 自动评测运行器
- `6.2` 端到端和失败恢复测试
- `6.3` 内容与隐私发布审核
- `6.4` 本地测试版发布

## 产品路线图里还没单独拆出来的项

来自 [思想记忆路线图](../docs/product/思想记忆路线图.md) 的三项最值得独立建计划：

- 哲学家影响轨迹
- 每周思想报告
- 反问质量机制

## 商业化待立项

来自功能 Beta 的 deferred backlog 和产品文档，还需要单独计划化：

- 账号隔离与云同步
- 多设备冲突合并与端到端加密
- 订阅、计费、额度、限流和成本控制
- 管理后台、审计和运维监控
- 隐私政策、删除流程和合规发布审核
- Obsidian 双向同步与插件化扩展

## 推荐顺序

1. 完成 `4.3`，把 Beta 收口。
2. 把旧 MVP 中仍未完成的 Obsidian / 档案 / 社交 / 发布项，回写成“延期到下一阶段”。
3. 新建一个商业化路线图，单独拆账号、同步、计费、隐私和运维。
4. 再单独立一份“思想记忆增强计划”，补哲学家影响轨迹、每周报告和反问质量。
