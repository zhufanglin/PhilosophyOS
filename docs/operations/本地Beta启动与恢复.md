# PhilosophyOS 本地 Beta 启动与恢复

## 启动

在仓库根目录双击 `scripts\start-dev.cmd`，或运行：

```powershell
.\scripts\start-dev.ps1
```

脚本固定使用 API `8001` 和 Web `5174`，确认两个服务健康后才打开页面。服务在后台运行，启动窗口可以关闭。电脑重启后再次运行同一个命令即可恢复。

API Key 不是启动条件。未配置模型时，页面会显示“模型尚未配置”，用户可在设置中填写免费模型、GPT 或 DeepSeek 的 Key。

## 重复启动

重复运行启动脚本会检查现有服务并复用，不会再创建一套冲突进程。如果端口被其他程序占用，脚本会明确指出冲突端口，不会自动换端口造成前后端失联。

## 状态与停止

```powershell
.\scripts\health-dev.ps1
.\scripts\stop-dev.ps1
```

也可以双击 `health-dev.cmd` 或 `stop-dev.cmd`。运行状态和日志保存在仓库的 `.runtime` 目录，该目录不会提交到 Git。

## 页面状态含义

- `知识服务在线`：本地后端和配置接口均可访问。
- `模型尚未配置`：后端正常，当前模型尚未填写 API Key。
- `知识服务离线`：后端没有启动；重新运行 `scripts\start-dev.cmd`。
- `后端响应异常`：端口可访问，但服务返回了异常响应；查看 `.runtime\api-error.log`。
- `网络连接异常`：请求被本机网络层拦截；检查防火墙或代理设置。

## 环境恢复

启动器不再依赖写死的 Python 或 Node 安装目录。它会优先使用系统命令，并兼容 Codex 工作区自带的运行时。如果 `.venv` 记录的 Python 路径已经失效，脚本会先尝试修复虚拟环境；缺少依赖时会给出准确的安装命令。
