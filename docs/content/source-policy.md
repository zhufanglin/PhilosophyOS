# 知识来源与引用规范

## 1. 目标

保证每项哲学知识能够追溯，避免模型伪造原文、页码、章节、作者立场或学界共识。

## 2. 来源等级

| 等级 | 类型 | 用途 | 展示标签 |
| --- | --- | --- | --- |
| S1 | 合法使用的原典、权威校勘本、作者文本 | 支撑直接引语和原典解释 | 原典 |
| S2 | 同行评审论文、大学出版社著作、权威学术百科 | 支撑学界解释和争议 | 研究解释 |
| S3 | 大学课程、可信导读、出版社说明 | 支撑入门解释和阅读路线 | 导读 |
| S4 | 人工整理的关系与摘要 | 用于检索导航，不单独支撑争议性结论 | 知识整理 |
| S5 | AI 综合 | 连接已有证据，不作为独立来源 | AI 推论 |

## 3. 首批来源池

### 3.1 权威参考

- Stanford Encyclopedia of Philosophy：人物、概念和学界争议入口。
- Internet Encyclopedia of Philosophy：入门解释与教学结构参考。
- Encyclopaedia Britannica：基础人物和历史信息交叉核验。
- PhilPapers：定位论文和研究脉络，不把索引页当作论证证据。

### 3.2 公共领域原典入口

- Project Gutenberg：核验具体版本的公共领域英文文本。
- Perseus Digital Library：古希腊、罗马文本及部分译文。
- MIT Internet Classics Archive：古典文本检索入口。
- Wikisource：仅作为文本入口，引用前核验版本、译者和底本。

### 3.3 中文资料

- 合法购买或获得授权的中文译本。
- 高校公开课程和出版社提供的合法试读内容。
- 国家哲学社会科学文献中心等合法学术检索渠道。
- 中文术语以主流学术译名为主，保留原文和常见别名。

来源是否可抓取、嵌入、展示全文，需要在接入前逐项核验服务条款和版权状态。本清单不等于自动获得使用授权。

## 4. 引用记录结构

每个文献片段至少保存：

```yaml
source_id: source_kant_cpr_zh_001
source_type: primary
author: 伊曼努尔·康德
title: 纯粹理性批判
translator: 待具体版本填写
edition: 待具体版本填写
language: zh-CN
chapter: 先验感性论
location: 版本相关定位
quote_allowed: false
license_status: review_required
retrieved_at: 2026-07-26
```

页码只在绑定到具体版本时保存。不同版本之间不得复用页码。

## 5. 回答生成规则

1. 直接引语只能来自 S1，并与原文片段逐字匹配。
2. “某哲学家认为”至少需要 S1 或两个相互印证的 S2 来源。
3. 学界存在争议时，列出主要解释，不写成唯一共识。
4. 只有摘要证据时使用转述，不加引号。
5. 未检索到证据时回答“当前资料不足”，不依靠模型记忆补齐。
6. AI 综合必须使用“可以理解为”“一种可能的联系”等措辞。
7. 原典与用户个人思考分别存储，不能互相覆盖来源属性。

## 6. 版权规则

- 默认只索引用户合法持有或明确授权的资料。
- 公共领域判断同时考虑作者死亡年、出版地、译者版权和具体版本。
- 受版权保护内容只保存检索所需的最小片段，不向用户展示大段原文。
- 不提供规避付费墙、复制整本书或移除 DRM 的功能。
- 删除来源后同步删除相应向量、缓存片段和派生引用。

## 7. 质量审核

每个 L3 人物上线前完成：

- 关键概念至少由两类来源交叉核验。
- 直接引语逐字核对。
- 中文译名、原文术语和别名核对。
- 常见误解由人工审核。
- 10 个问答回归案例通过。
- 争议内容没有把单一解释写成共识。

## 8. 来源状态

| 状态 | 含义 |
| --- | --- |
| discovered | 已发现，尚未评估 |
| rights_review | 正在确认版权或使用条款 |
| approved | 可按标注范围使用 |
| restricted | 只允许元数据或极短引用 |
| rejected | 不进入知识库 |
| retired | 已停止使用并从索引移除 |
