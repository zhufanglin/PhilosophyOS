# 西方哲学内容地图

## 1. 组织方式

内容使用两条相互连接的主轴：

- **历史轴：** 展示哲学家、著作、概念和争论如何从古希腊发展至当代。
- **问题轴：** 围绕知识、存在、自由、善、幸福、意义、正义和科学等问题跨时代比较。

用户可以从人物进入问题，也可以从问题回到不同时代的人物。产品不把哲学史做成单纯年代背诵。

## 2. 内容深度等级

| 等级 | 必备内容 | 用途 |
| --- | --- | --- |
| L1 时间线 | 时代、地域、核心问题、主要概念、代表著作、前后影响、至少 1 个来源 | 保证从古至今不断档 |
| L2 基础学习 | L1 + 思想概述、关键论证、常见误解、3 个来源、关联问题 | 支持普通问答与每日挑战 |
| L3 深度学习 | L2 + 原典片段、论证结构、主要争议、版本/译名说明、延伸阅读 | 支持可信 RAG 和深入讨论 |

## 6. 编辑工作单元

每位人物按同一工作单元制作：

1. 身份与时代定位。
2. 他试图解决的 3–5 个问题。
3. 5–10 个核心概念及别名。
4. 2–5 部代表著作。
5. 一条思想来源链和一条影响链。
6. 至少一项常见误解或概念校正。
7. 原典、权威解释和争议观点分层。
8. 可用于每日挑战的 3 道问题。
9. 与用户现有笔记的潜在连接。

## 7. 中国哲学后期扩展原则

中国哲学作为 Phase 4 单独建设，不追加在西方时代轴末尾。届时建立先秦诸子、两汉经学、魏晋玄学、隋唐佛学、宋明理学和近现代中国哲学时间轴，并使用中国经典、注疏与概念谱系。跨传统比较必须说明比较维度和不可直接等同之处。
