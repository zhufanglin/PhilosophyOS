# 核心页面低保真原型

## 1. 导航结构

```text
┌──────────────────────────────────────────────────────────┐
│ PhilosophyOS   今日  对话  探索  好友  思想档案  笔记工作台 │
└──────────────────────────────────────────────────────────┘
```

桌面端使用左侧固定导航；移动端使用底部导航，保留“今日、对话、档案、更多”四个入口。

## 3. 思辨对话页

```text
┌──────────────┬──────────────────────────────┬──────────────┐
│ 对话脉络      │ 讨论区                        │ 相关材料      │
│              │                              │              │
│ ① 初步观点    │ 你：我觉得有原因也不代表被迫  │ 旧观点        │
│ ② 概念澄清    │                              │ 2026-07-25   │
│ ③ 反例检验    │ AI：你这里说的“属于我”，是指 │ 暂定相容论    │
│ ④ 实践含义    │ 能按愿望行动，还是能反思愿望？│              │
│              │                              │ 文献          │
│              │ [输入你的回答……]             │ 斯宾诺莎      │
│              │                              │ 丹尼特        │
│              │ [提示] [相关观点] [结束总结]  │              │
└──────────────┴──────────────────────────────┴──────────────┘
```

右侧材料默认折叠，避免文献内容抢走用户的初步思考。移动端将“对话脉络”和“相关材料”放入抽屉。

## 7. 探索页

MVP 不显示复杂力导向图，而使用稳定的时间线和关系列表：

```text
古希腊 ─ 中世纪 ─ 近代 ─ 启蒙 ─ 19 世纪 ─ 20 世纪 ─ 当代
                              │
                            康德
                 来源：休谟、卢梭
                 概念：先验、自主、定言命令
                 影响：费希特、黑格尔
                 [查看人物] [进入相关问题]
```

中国哲学上线后使用独立时间线，通过“跨传统比较”入口进入，不与西方时间线拼接成单一进步序列。

```text
┌──────────────┬──────────────────────────────┬──────────────┐
│ 参与者        │ 道德是否需要普遍标准？        │ 讨论脉络      │
│ 你            │                              │ 共同点        │
│ 林            │ 你：如果标准完全个人化……     │ 分歧          │
│ AI 主持：开启 │ 林：但普遍标准也可能压制……   │ 未解决问题    │
│              │                              │              │
│ [邀请设置]    │ AI：你们对“普遍”的含义似乎不同│ [请求总结]    │
│ [退出房间]    │ [输入消息……]                 │              │

```

讨论结束后进入“双层总结”：房间共同总结对所有成员可见；个人总结只对本人可见，确认后才能进入思想档案或 Obsidian。

## 11. 交互原则

- 每个页面只有一个主要行动。
- 哲学正文使用适合长读的行宽，工具栏保持紧凑。
- 不使用过度游戏化装饰；连续记录只作为温和反馈。
- 所有 AI 生成的长期结论都必须有确认状态。
- 引用、观点主体和写入目标在执行前始终可见。
